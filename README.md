# My Deloitte Data Analytics Journey

This repository showcases my work during the Deloitte Australia Data Analytics Job Simulation. Rather than sticking to standard manual tools, I pushed myself to solve every challenge using Python, turning raw data into actionable business insights.

## The Why
As a computer applications student, I believe that automation is the key to efficiency. For this project, I moved away from manual spreadsheet work and built custom scripts to handle data cleaning, visualization, and logic-based classification.

## What I Built

### Uncovering the Osaka Mystery (Operational Analytics)
Deloitte needed to know why their factories were slowing down. I took a massive, messy JSON file of machine logs and:
* **Wrangled the Data**: Flattened the nested structures into something readable using Pandas.
* **Visualized the Truth**: Created bar charts that clearly showed Osaka was struggling due to Laser Welder failures.
* **The Result**: A data-backed recommendation to focus maintenance on specific high-impact machines.

### Automating Fairness (Forensic Technology)
Next, I analyzed gender pay equality by bridging the gap between code and corporate reporting.
* **The Logic**: Instead of manually labeling hundreds of rows, I wrote a Python script to categorize "Equality Scores" based on their deviation from zero.
* **The Engine**: Using Openpyxl, I generated a final Excel tool that the HR department could use immediately.
* **The Philosophy**: Fairness shouldn't be a manual task—I proved it could be automated with precision.
